# R2 object storage

R2 stores objects. Its S3 API lets S3 clients work with it.

## S3 endpoint

- Endpoint pattern: `https://<account_id>.r2.cloudflarestorage.com`. Replace `<account_id>` with the account ID from the environment, for example `${CLOUDFLARE_ACCOUNT_ID}`.
- Region: `auto`. A client that cannot set a region can leave it blank or use `us-east-1`. Both map to `auto`.
- The vendor page says: "R2 implements the S3 API to allow users and their applications to migrate with ease."

## Token scope

- An Object permission can be scoped to a set of buckets.
- Object Read only allows reading and listing objects in the named buckets. Object Read & Write adds writing.
- The vendor page does not describe bucket scoping for the Admin permissions. Admin permissions cover account-level bucket management.
- Object-level permissions work only with the S3 API, not the Cloudflare REST API.
- Working rule: scope each token to one bucket and one permission.
